# Cybersecurity Checklists

A collection of practical cybersecurity checklists designed for businesses and public sector organizations.

## Available Checklists

### MFA Deployment Checklist

- Identify critical accounts
- Enforce MFA for administrators
- Review recovery procedures
- Test emergency access workflows

### FIDO2 Adoption Checklist

- Inventory supported services
- Register security keys
- Configure backup authentication methods
- Train end users

### Electronic Signature Security Checklist

- Verify certificate validity
- Protect authentication tokens
- Control signing permissions
- Monitor certificate expiration dates

### Security Awareness Checklist

- Phishing awareness training
- Password hygiene review
- Incident reporting procedures
- Access review process

## Purpose

These resources help organizations improve security posture and reduce operational risks.
